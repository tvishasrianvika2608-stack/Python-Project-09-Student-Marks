# Project 9: Student Marks Matrix Analysis

## Problem Description
This project analyses a matrix of student marks across multiple subjects. It calculates student-wise totals and averages, subject-wise totals and averages, identifies the top-performing student or students, and detects subjects with low average performance.

## Programming Language
Python

## Concepts Used
- Variables and data types
- Lists and nested lists
- For loops
- Conditional statements (if, else)
- Arithmetic operators
- Matrix operations
- User input and output

## Files Included
- `Question_09_Student_Marks.py` – Python source code
- `Screenshots/` – Code and output screenshots

## How to Run
1. Download the Python file.
2. Open it using Python or VS Code.
3. Run the program.
4. Enter the names of three students.
5. Enter their marks in Python, Mathematics, and English.
6. View the student-wise and subject-wise analysis report.

## Conclusion
The program analyses student marks using a nested list, calculates totals and averages, identifies top performers, and displays subjects with low average marks.
